## 第四章 断裂登记簿草案（按 STRAT §8.3：二选一，禁止"实践例外"）

> 以下每条给出冲突描述+双方依据+两个合法选项的裁决材料。登记与裁决归 S5；本表是证据，不是决定。

### FR-01 ｜ 全公开政策 vs 判定资产永不出域（最大断裂）

- **DGA 侧**：STRAT §3.2 红线"holdout 的答案域永不进入任何执行级端点的上下文"；§5.4 许可证矩阵"eval 答案域、holdout、判例库、私有 spec 全文→永不出域"（护城河=判定资产的时间积累）。
- **现状侧**：ADR-0020 全仓公开政策（"未来确需私有仓，须新 ADR 推翻本决策"）；holdout 仓公开但引用纪律+诱饵检测（IR-0001 DECISION-02："agent 读公开仓是不确定风险，私有化的运维是确定支出"）。
- **新证据（本次调研）**：GitHub 服务条款（2026-04-27 生效）D.4 明确：用户授予 GitHub 及关联公司（含 Microsoft）对**公开仓库内容**"训练 AI 功能与训练/开发 AI 模型"的许可；私有仓内容受保密承诺、仅经 AI 功能输入且可 opt-out（J.3）。**即：现状下 holdout 条目、evalsets、ADR 判例、全部 spec 正在向 GitHub/Microsoft 及一切公开抓取者授出训练权与读取权。**
- **裁决材料**：
  - 选项 A（实例修正，维持全公开）：接受"判定资产公开"作为本组织采样点，理由成立的话是：考卷的**引用纪律与揭封门禁**已使公开 payload 无法被 spec 实现侧合法消费；对外抓取者，判定资产的护城河在**校准与判例的积累过程**而非条目本身（STRAT §1.2"模仿瓶颈从理解变为时间"——公开条目不公开积累过程）。同时按 FR-02 修 DGA §5.4 措辞。代价：理论上"公开侧永远拟合不了私有判定基准"（STRAT §4.2）在本组织不成立，需在 DGA 中显式降级为"非本组织采样点"。
  - 选项 B（理论胜出，建最小真值区）：为新 ADR 推翻 ADR-0020 的适用范围——**仅 holdout 答案域/evalsets 答案层迁私有**（或 hash-only 化：公开指针+私有 payload），其余维持公开。代价：私有仓触发 GitHub 计费（ADR-0096 已登记"删除重建不可再用"）；违反"agent 读公开仓"成本裁决；运维面+1。
  - 选项 C（混合，代价最低）：维持公开，但把 holdout 的**答案层**（golden 断言值、判分逻辑）从条目 payload 剥离为密文 blob（T-10 工具就位后），场景描述保持公开——"考卷公开、答案密封"。与现有 seal.py 基建兼容。
- **建议裁决时点**：灾备建设（T-03）之前——密文镜像的内容选择取决于本条裁决。

### FR-02 ｜ 许可证矩阵：MIT/Apache vs AGPL

- **DGA 侧**：STRAT §5.4 自有实现层→AGPL（网络条款封锁"取实现改作托管竞品"）。
- **现状侧**：产品仓 MIT 为主、AI_Web_School Apache-2.0、治理仓（.github/CI-Workflows/archive/arbiter/holdout 等）**无许可证**；ADR-0098 曾做"media-monitor license gate 全量移除"、ADR-0026 dep-review 许可证豁免先例。
- **裁决材料**：选项 A 实例修正——一人公司冷启动期以宽松许可换分发（STRAT §5.4 同段自己也说"规格公开部分是生态与获客工具"），把治理仓补 MIT/Apache、产品仓维持现状，DGA §5.4 采样注记"AGPL 为默认、可逐仓偏离并登记理由"；选项 B 理论胜出——新仓迁 AGPL（成本：存量 9 仓 relicense 需唯一著作权人同意=owner 本人，法律上可行）。两选项均需给**治理仓补许可证**（现状无证=默认保留所有权利，与全公开获客意图矛盾）。

### FR-03 ｜ 灾备缺失（唯一硬缺口，无裁决需求）

- DGA STRAT §4.3"≥2 独立平台密文只读镜像、同步单向、恢复演练周期化" vs 宪法 §10.1"接受 GitHub 单点残余"+archive README 占位。**两份内部文件已经方向一致（都承认该做），只差执行**。选型证据见选型文档 T-03/T-10；建议复用 IR-0006 的 GM-1 对账模式（pipefail/分通道/指纹去重/自动关四件套——W35 报告自证第三个对账面可直接抄 env-drift 骨架）。

### FR-04 ｜ 双波次体系：DGA-MIGRATION W0-W6 vs IR-0006 W1-W6

- 两套"波次"词汇并存且语义不同（组织基建波次 vs 总纲吸收波次）。**裁决材料**：DGA 文档族收编时（IR-0007）显式声明：DGA-MIGRATION 的 W 编排**不作独立执行计划**，其门禁思想并入既有 IR 流；迁移类工作以后走正常 IR（MIG 本身降级为"方法论备忘"）。否则双 SSOT（ADR-0103 决策 6 的"防双 SSOT"原则直接适用）。

### FR-05 ｜ DGA-A 生产装载 vs AGENTS.md 协议块

### FR-06 ｜ DGA 文档族本身在 git 外（元断裂，建议最高优先）
