## 第三章 宪法 v2.4（治理体系的公理层）

签署 2026-08-21（v2.3 跨族红队清零版），2026-08-29 增补 §14（v2.4，吸收"治理战略总纲 v1.0"三组条款）。核心条款：

- **§0 一句话**：GitHub 组织即工厂；系统压缩一切操作性工作，判断工作（做什么、对谁负责、不可逆裁决）不可压缩，归 owner。**LLM 只做生成、veto 与叙述，永无合并权、approve 权、授权裁决权。**
- **§1 七层仓**：法律/机器/仲裁内核/资产/记忆/试卷/工地，仓即职责；仲裁内核独立于管家（消掉"被审计者组装审计报告"的结构性冲突）。
- **§3 三流水线+两服务**：Feature 流（IR→spec→红队→卡→测试先行→实现→对抗→verdict→信任门→合并）、Bug 流（复现前置三值判定 {复现/证伪/不可判定}）、Hygiene 流；patrol（三源场景生成）与 security-response。
- **§4 验证体系（司法，三层）**：T1 确定性关卡全景（变异/负控制/CRAP/架构依赖/AI 导航度量/禁用模式/棘轮）；T2 校准 LLM verifier（入职考试=RewardBench2+LLMBar+null 金丝雀，连续分+校准集+标注负债申报，veto-only）；T3 品味残余（AGENTS.md≤30 行索引型，可判定规则禁入）。**判定物有效性本身是关卡**：每周向随机 PR 注入已知缺陷（seed-drill），关卡必须红。
- **§5 信任演进**：硬谓词白名单（fail-closed）+常设 shadow 模式替代风险标量；域解锁=连续 ≥50 例一致且零逃逸；前三解锁域已指定。
- **§6 fail-closed**：缺席即停、外部 dead-man 心跳、种子缺陷演习、holdout 泄漏诱饵、熔断一键停自动合并。
- **§7 反退化**：owner 每周从原始事件日志独立复算（不用管家组装的包）、每周亲手一件真事、决策卡第三选项"都不对"。
- **§8 度量**：北极星对（零接触合并数×质量护栏互锁）、注意力会计（签署耗时/needs-human p90/每合并 owner 分钟）、成本熔断、用户结果指标防 oracle 友好漂移。
- **§9 公共知识地图与署名规则**（宪法级）：一切外部范式/工具/基准引用必须显式署名 arXiv 号/仓库 URL。十大原子问题各自站在谁肩上一表列明（OpenSpec/StrictDoc/EARS、OCR、LLM-as-a-Verifier、Stryker/mutmut、dep-cruiser、SWT-bench、Prow、promptfoo/inspect_ai、Semantic Entropy、Google/Uber flaky 治理）。
- **§10 已知代价（诚实清单）**：GitHub 供应商单点、判断预算 2-3h/周、OCR 低召回、T2 标注负债、公开仓攻击面、shadow 期 4-8 周。
- **§11 唤醒矩阵+统一入口**：管家永不自己醒来（每次运行有触发器+审计条目）；陌生 agent 经各仓 AGENTS.md 同一协议块进入（ghcb next→claim（arbiter CAS）→make card-test→PR 带 Card: 元数据）。
- **§12 三投影**：label 唯一真源；Project 板/dashboard/human-brief 均为只读投影，漂移以 label 为准。
- **§13 业务假设**：软件形态迁向"被模型调用的 harness"；公司内核=harness 群；FDE 交付模式。数据飞轮推论：事件 JSONL/golden 集/校准集/红队报告=战略资产。**"现在不建"清单**：训练管线、数据策展、客户交付管线、多角色组织治理。
- **§14 三面分离+证据账本三层**（v2.4）：声明面（Git）/执行面（GitHub Actions+云内网+CNB 池）/判定面（恒定 GitHub CI，**判定锚点永不外置**）；证据账本=判定层（archive，append-only+hash 链，链断=红）/轨迹层（blob，4KB 拒写）/丢弃层（事件面）；每条判定记录必含 tenant 字段；飞书多维表格=第四投影（outbound-only，drop & rebuild 保真）。

## 第八章 已知风险面（现状自报 + 实测补充）

1. **供应商单点**：GitHub=计算+存储+身份+事件总线+人机界面（宪法 §10.1 承认）；**异地备份策略仍为占位注记**（archive README 自报"后续波次落位"）——本快照实测：无任何第二平台镜像。
2. **全公开攻击面**：front-desk/仲裁/红队读未受信文本；INV-10 防线+频控（宪法 §10.5）。
3. **组织 2FA 未强制**（API 实测 false）——单账号持有全部 admin bypass（ADR-0090：所有 ruleset org admin 可 bypass）。
4. **T2 verifier 标注负债**：模型换代即重标（宪法 §10.4）。
5. **判定链单通道**：llm-verifier 唯一 LLM 通道，无第二判定级端点冗余（T-04 相关）。
6. **个人 PAT 在日常流程中的残余**：ADR-0103 决策 5 已裁决"个人 PAT 退出日常流程（应急回退 24h 窗口）"；owner 在会话中传递 PAT 的操作仍会出现（本次分析即经会话获得 PAT——**建议用后轮换**）。
