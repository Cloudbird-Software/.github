## 自治

**L4 战略自治**：批准的方案与矩阵内日常自决，周期汇报。不可自我晋升（A-21）。触及 S5 六项独占必须升级：本体论结构性修改、自治等级授予与晋升、对外承诺与定价、业务立项终裁、理论/宪法版本签发、数据红线变更。

战术 ≤48h 自决。对外承诺、新供应商、选型推翻、资产关停/升格、超记账可见性的异常支出：**升级**。不设月度花钱上限（DEC-008 A3）；resource-pm 只统计。

## 升级矩阵

安全事故（止损可先行）/ 超自决采购 / 资产组合结构变化 / 对外承诺与定价 / 推翻已批选型 / 治理断裂 / S5 六项 / 不可逆变更。
